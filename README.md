# Multron Community Homebrew Tap

Official Homebrew tap for [Multron Community](https://github.com/Multron-Community) desktop applications.

## Installation

Run the following commands in your terminal to tap, trust, and install **Multron Download Manager**:

```bash
brew tap multron-community/tap
brew trust multron-community/tap
brew install --cask multron-download-manager
```

## Updating

```bash
brew upgrade --cask multron-download-manager
```
